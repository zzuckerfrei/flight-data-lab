# 수집 영역(bbox) 좌표 + 크레딧 설계

> OpenSky `/states/all` 수집 대상 영역과 크레딧 예산.
> 분쟁지역 영공 회피 패턴(공백 + 우회 집중) vs 정상 비교지역 대조.
> 확정일: 2026-06-30

## 1. 영역 좌표 (확정)

| 영역 | 유형 | lamin | lamax | lomin | lomax | 면적(sq°) | 크레딧 |
|---|---|---|---|---|---|---|---|
| 우크라이나+흑해 | 분쟁 | 42 | 55 | 18 | 44 | 338 | 3 |
| 중동(이란-이라크-걸프) | 분쟁 | 24 | 42 | 36 | 66 | 540 | 4 |
| 서유럽 | 비교 | 45 | 52 | 2 | 12 | 70 | 2 |
| 한국 | 비교 | 33 | 39 | 124 | 132 | 48 | 2 |
| | | | | | | **호출당 합계** | **11** |

- 면적 = (lamax−lamin) × (lomax−lomin). 크레딧: ≤25→1 / 25~100→2 / 100~400→3 / 전역→4.
- **2026-07-21 확대**: Kepler 지도로 확인 결과 분쟁지역 bbox가 타이트해 "본토 공백 + 주변국 우회"를 한 프레임에 못 담음 → 우크라·중동 확대(우크라 162→338, 중동 375→540, 중동은 400 초과로 3→4크레딧). 확대 시점부터 새 영역(과거 데이터는 옛 bbox, 분석 시 경계 불일치 주의).

## 2. 크레딧 예산

| 주기 | 호출/일 | 일일 크레딧 | 4000 대비 |
|---|---|---|---|
| **10분 (확정)** | 144 | **1,584** | **40%** ✅ |
| 5분 (대안) | 288 | 3,168 | 79% |

- 등록 티어 4,000/일, daily refill. **10분 간격 = 1,584 크레딧/일**로 60% 안전마진(토큰 갱신 실패·재시도·디버깅 여유 포함).
- 3주 누적: 144회/일 × 21일 ≈ **3,000 스냅샷** → 밀도 시계열 충분.

## 3. 설계 의도

- **분쟁지역(우크라이나·중동)은 일부러 넓게**: 영공 회피 신호 = "본토 상공 공백 + 가장자리·우회로 집중"을 **동시에** 담아야 하므로 좁히면 안 됨.
  - 우크라이나: 본토 공백 + 서쪽(폴란드·루마니아) 우회 + 흑해 + 러시아 서부 접경.
  - 중동: 이란 상공 공백 + 터키 북부·걸프 남부 우회. lomax 63으로 이란 동부까지 포함.
- **비교지역(서유럽·한국)은 정상 밀도**: "공백이 분쟁 탓이지 원래 한산한 게 아님"을 입증하는 대조군.

## 4. 운영 노트

- **좌표는 config로 분리**(Airflow Variable 또는 DAG 파라미터) → 코드 수정 없이 영역 변경 가능.
- **수집은 넓게, 분석에서 좁히기**: OpenSky는 과거 1시간만 제공 → 좌표를 좁게 잡으면 나중에 넓힐 때 과거 데이터 소급 불가. 넓게 모아두고 dbt/시각화 단에서 필터링하면 **재수집 없이** 영역 실험 가능.
- 크레딧 소진 시 `429` + `X-Rate-Limit-Retry-After-Seconds` → backoff 재시도.

## 6. 확장 아이디어 (스코프 밖, 발표·블로그용)

- **러시아 영공 전체 우회**(유럽↔동아시아 항로의 시베리아 회피)는 대륙 규모라 크레딧 폭증 → 이번 스코프 제외. 언급만.
- 우회로를 별도 영역으로 세분화(흑해 항로·카스피 회랑) — 데이터 확인 후 dbt 단에서 분리 가능.
