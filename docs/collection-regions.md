# 수집 영역(bbox) 좌표 + 크레딧 설계

> OpenSky `/states/all` 수집 대상 영역과 크레딧 예산.
> 분쟁지역 영공 회피 패턴(공백 + 우회 집중) vs 정상 비교지역 대조.
> 확정일: 2026-06-30

## 1. 영역 좌표 (확정)

**2026-07-22 재설계: 큰 박스 → 전세계 raw 수집.** 수집은 전세계(bronze 자산), 분석은 관심 지역(dbt stg에서 필터).

**수집 박스 (global)**
| 이름 | lamin | lamax | lomin | lomax | 면적(sq°) | 크레딧 |
|---|---|---|---|---|---|---|
| global | -90 | 90 | -180 | 180 | 전세계 | **4** |

- 크레딧: ≤25→1 / 25~100→2 / 100~400→3 / **>400·global→4(상한)**. 전세계도 큰 박스(3,360sq°)도 똑같이 4크레딧(실측).
- **왜 전세계 raw?** 크레딧 동일한데 raw를 전세계로 쌓아두면 나중에 다른 주제(대서양·북극 항로, 특정 공항 등)도 **재수집 없이** 분석 가능(OpenSky 과거 1h만 제공 → 지금 안 모으면 영영 없음). **"수집은 넓게(자산), 분석은 좁게(효율)"** — bronze는 원본 창고, 가공은 목적별.
- **분석 처리는 관심 지역만**: dbt stg_states에서 유럽~중동 큰박스(lon -10~70, lat 18~60)로 필터 → 무관 전세계는 bronze에만 남고 UNNEST·mart·지도 부하 제외.

**분석 region (dbt stg_states 위경도 파생)** — region_area.csv 면적으로 밀도 정규화
| region | lon | lat | 면적(sq°) | 용도 |
|---|---|---|---|---|
| ukraine | 18~44 | 42~55 | 338 | 분쟁(영공 공백) |
| middle_east | 36~66 | 24~42 | 540 | 분쟁(영공 공백) |
| west_europe | 2~12 | 45~52 | 70 | 비교(정상 밀도) |
| other | 그 외 | | — | 주변 배경(지도용, 밀도 계산 제외) |

- 한국은 큰 박스에서 멀어 제외(서유럽이 비교군 역할).

## 2. 크레딧 예산

| 주기 | 호출/일 | 일일 크레딧 | 4000 대비 |
|---|---|---|---|
| **10분 (확정)** | 144 | **576** | **14.4%** ✅ |
| 5분 (대안) | 288 | 1,152 | 29% |

- 등록 티어 4,000/일, daily refill(정확 시점 미명시—UTC 자정 or 가입기준 rolling 불명). **10분 간격 = 576 크레딧/일**로 85% 안전마진. 큰 박스 1개(4크레딧)라 4분할(11)보다 크게 절약.
- 🟡 rate limit이 IP/세션별로 분리 카운트되는 듯(로컬 헤더로 클러스터 실소모 측정 불가). 실질 한도 지표 = 429 발생 여부(현재 0건).
- 3주 누적: 144회/일 × 21일 ≈ **3,000 스냅샷** → 밀도 시계열 충분.

## 3. 설계 의도

- **분쟁지역(우크라이나·중동)은 일부러 넓게**: 영공 회피 신호 = "본토 상공 공백 + 가장자리·우회로 집중"을 **동시에** 담아야 하므로 좁히면 안 됨.
  - 우크라이나: 본토 공백 + 서쪽(폴란드·루마니아) 우회 + 흑해 + 러시아 서부 접경.
  - 중동: 이란 상공 공백 + 터키 북부·걸프 남부 우회. lomax 63으로 이란 동부까지 포함.
- **비교지역(서유럽·한국)은 정상 밀도**: "공백이 분쟁 탓이지 원래 한산한 게 아님"을 입증하는 대조군.

## 4. 운영 노트

- **좌표는 config로 분리**(Airflow Variable 또는 DAG 파라미터) → 코드 수정 없이 영역 변경 가능.
- **수집은 넓게, 분석에서 좁히기**: OpenSky는 과거 1시간만 제공 → 좌표를 좁게 잡으면 나중에 넓힐 때 과거 데이터 소급 불가. 넓게 모아두고 dbt/시각화 단에서 필터링하면 **재수집 없이** 영역 실험 가능.
- 크레딧 소진 시 `429` + `X-Rate-Limit-Retry-After-Seconds` → backoff 재시도.

## 6. 확장 아이디어 (스코프 밖, 발표·블로그용)

- **러시아 영공 전체 우회**(유럽↔동아시아 항로의 시베리아 회피)는 대륙 규모라 크레딧 폭증 → 이번 스코프 제외. 언급만.
- 우회로를 별도 영역으로 세분화(흑해 항로·카스피 회랑) — 데이터 확인 후 dbt 단에서 분리 가능.
